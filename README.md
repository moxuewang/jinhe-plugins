# 锦盒插件

新装锦盒默认已装 PDF 转 TXT 和三个音乐插件。其他插件可卸载，也可按需从这里补回。

使用方法：

1. 按分类选择需要的插件。
2. 下载这一行对应的单插件 ZIP。
3. 在锦盒打开「工具与插件」→「导入插件包」，选择刚下载的 ZIP 文件。

每个 ZIP 只包含一个插件。
